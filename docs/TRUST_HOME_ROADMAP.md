# Roadmap: Trust-блоки и главная страница

Этот документ - рабочий чеклист для разработки trust-блоков, отзывов и обновленной главной страницы Fashion Demon.

Статус на 2026-06-16: базовая реализация завершена и проверена на локальной базе PostgreSQL.

Выполнено:
- [x] Добавлены публичные настройки `home_trust_*` для hero, преимуществ, блока "О нас" и отзывов.
- [x] Добавлен раздел "Главная" в админке для ручного управления всеми новыми блоками.
- [x] Главная страница получает данные из API публичных настроек и использует fallback при пустых/битых значениях.
- [x] Otzovik не парсится: отзывы редактируются вручную, источник и ссылка задаются в админке.
- [x] Убраны дефолтные упоминания Poizon.
- [x] Исправлена видимость контурной кнопки в темных продуктовых секциях.
- [x] Добавлены тесты нормализации настроек и безопасных ссылок.
- [x] Сделаны скриншоты результата: `.codex-temp/screenshots/`.

Статусы:
- `[ ]` не начато
- `[~]` в работе
- `[x]` готово

Правило работы: после каждого завершенного блока агент обязан приложить скриншот результата на desktop и mobile, а также список пройденных тестов.

## 0. Подготовка

- [ ] Изучить текущую архитектуру главной страницы, админки, API настроек и БД.
- [ ] Найти существующий механизм настроек сайта/главной страницы.
- [ ] Определить, куда правильно добавить новые настройки: `app_settings`, отдельные таблицы или существующие сущности.
- [ ] Зафиксировать текущий внешний вид главной до изменений скриншотами:
  - desktop
  - mobile

Результат: понятно, где хранить настройки и как не сломать текущую админку.

Скрин после этапа: текущая главная до изменений.

Тесты: проверка сборки.

## Definition of Done

Задача считается выполненной только если:

- [x] Все новые блоки управляются через админку.
- [x] Нет хардкода контента, кроме дефолтных сидов.
- [x] Otzovik не парсится.
- [x] Отзывы добавляются вручную.
- [x] Все блоки можно скрывать/показывать.
- [x] Все визуально совпадает со стилистикой Fashion Demon.
- [x] Мобильная версия проверена.
- [x] Невидимая кнопка исправлена.
- [x] Все реализованные части покрыты тестами.
- [x] После каждого этапа приложены скриншоты.
- [x] Сборка frontend проходит.
- [x] Сборка backend проходит.
- [x] Нет регрессий в существующей главной, каталоге и админке.
